Data Access

Reduced data products from the Aether survey — NIRSpec IFU cubes, extracted 1D spectra, and associated calibration files — will be made available here following the program's proprietary period.

Data policy. As a JWST Survey-category program, Aether data become public on release from STScI. Reduced, science-ready products will be posted on this page as they become available; raw data can be retrieved directly from MAST using Program ID 5645.
